## Lessons re-learned (already in playbook, captured here so they stick)

- **PowerShell 5.1 reads BOM-less `.ps1` as Windows-1252.** Em-dashes and arrow chars (`<-`) corrupt the parse. All `.ps1` files in this repo are now ASCII-only and parser-validated with `[Parser]::ParseFile()`.
- **`2>&1 | Out-Null` swallows real errors.** First version of `install-reliability-patch.ps1` silently failed to set `AppDirectory`, leaving the service pointed at `C:\Program Files\Volta` (cwd of node.exe). Symptom: service installs cleanly, starts, instantly exits, no log output. Fix: don't swallow stderr from nssm.
- **Self-elevating `.bat` files are unreliable on UAC-restricted accounts.** "BUILTIN\Administrators / Group used for deny only" means even admin accounts start filtered. Right-click -> Run as administrator is the reliable path. Documented in FAQ.
- **Always restart only YOUR own processes when freeing a port.** PID 19592 (the original bare-process Next.js launched elevated) couldn't be killed from the non-elevated shell that needed to replace it.
